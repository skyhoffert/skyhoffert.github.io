BLENDER INFORMATION:

COLL_BOX_<xyz> is for all colliders, as primitives
COLL_SPHERE
COLL_CYLINDER

SW (switches) do name matching for toggling.
SW_room maps to LIGHT_room_a and LIGHT_room_b

DOOR_ prefix used for doors

SPAWN_<name> should be defined in map's json file.
